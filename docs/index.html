Linux runtime / Kubernetes CRI v1

OCI containers,
WASI and Pod VMs.

Run OCI containers directly on Linux or in a dedicated VM per Pod. Run WASI commands with Wasmtime. The Nautilus CLI and kubelet use the same CRI socket.

Install Nautilus

Run your first workload

OCI containers

Pull BusyBox from the registry, print a greeting, then remove the container and its sandbox. Nautilus caches the image for the next run.

sudo nautilus run --rm busybox:1.36 echo hello

WebAssembly commands

Place a WASI Preview 1 module exporting _start in your current directory. The wasi handler runs it in Wasmtime and records stdout and stderr in the container’s CRI log.

sudo nautilus run --rm --runtime wasi "file://$PWD/hello.wasm"

Pod VMs

On a KVM node with the vm handler enabled, run BusyBox inside its own Linux guest and print the guest kernel version.

sudo nautilus run --rm --runtime vm busybox:1.36 uname -r
