Linux runtime / Kubernetes CRI v1

Run containers
and WebAssembly.

Nautilus runs OCI images and WASI commands on Linux. Its Rust daemon serves both the Nautilus CLI and kubelet over one Unix socket.

Install Nautilus

Run your first workload

OCI containers

Pull BusyBox from the registry, print a greeting, then remove the container and its sandbox. Nautilus caches the image for the next run.

sudo nautilus run --rm busybox:1.36 echo hello

WebAssembly commands

Place a WASI Preview 1 module exporting _start in your current directory. The wasi handler runs it in Wasmtime and sends output to the daemon log.

sudo nautilus run --rm --runtime wasi "file://$PWD/hello.wasm"
